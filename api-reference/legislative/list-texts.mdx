Returns the published versions of a bill's text, ordered by publication date, oldest first. Versions without a publication date are listed last.

This endpoint returns metadata only. To retrieve the full text of a version, use [Get bill text version](/api-reference/legislative/get-text).

## Path parameters

<ParamField path="bill_id" type="string" required>
  The `id` of the bill.
</ParamField>

## Response

<LimitOffsetResponse />

<ResponseField name="results" type="array">
  Array of text versions, oldest first.

  <Expandable title="Text version fields">
    <ResponseField name="id" type="string">
      UUID of the text version.
    </ResponseField>
    <ResponseField name="external_id" type="string">
      The text version's ID in the legislature's own system.
    </ResponseField>
    <ResponseField name="title" type="string">
      Title of the text version, such as `"HL Bill 57"`. Empty if unavailable.
    </ResponseField>
    <ResponseField name="publication_type" type="string">
      Type of publication, as given by the legislature. Empty if unavailable.
    </ResponseField>
    <ResponseField name="publication_date" type="string | null">
      When the text version was published (ISO 8601).
    </ResponseField>
    <ResponseField name="is_current" type="boolean">
      Whether this is the bill's current text.
    </ResponseField>
    <ResponseField name="pdf_url" type="string">
      URL of the PDF version on the legislature's website. Empty if unavailable.
    </ResponseField>
    <ResponseField name="html_url" type="string">
      URL of the HTML version on the legislature's website. Empty if unavailable.
    </ResponseField>
    <ResponseField name="download_url" type="string">
      URL that Parsagon downloaded the text from. Empty if unavailable.
    </ResponseField>
    <ResponseField name="source" type="string | null">
      `uuid` of the `"LEGISLATION"` source that holds the extracted text. `null` until the text is extracted.
    </ResponseField>
    <ResponseField name="has_text" type="boolean">
      Whether the extracted text is available from [Get bill text version](/api-reference/legislative/get-text).
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Meaning |
|---|---|
| `403 Forbidden` | Your account doesn't have a valid subscription or hasn't accepted the Terms of Service. |
| `404 Not Found` | No bill has this `id`, or the bill belongs to a jurisdiction you can't access. |
