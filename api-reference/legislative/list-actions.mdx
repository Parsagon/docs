Returns the steps in a bill's history, such as readings, stages, decisions, and publications, oldest first. This is the bill's full history from the legislature, including steps from before Parsagon started tracking the bill.

## Path parameters

<ParamField path="bill_id" type="string" required>
  The `id` of the bill.
</ParamField>

<LimitOffsetParams />

## Response

<LimitOffsetResponse />

<ResponseField name="results" type="array">
  Array of actions, oldest first.

  <Expandable title="Action fields">
    <ResponseField name="id" type="string">
      UUID of the action.
    </ResponseField>
    <ResponseField name="external_id" type="string">
      The action's ID in the legislature's own system.
    </ResponseField>
    <ResponseField name="date" type="string | null">
      When the action happened (ISO 8601).
    </ResponseField>
    <ResponseField name="house" type="string">
      The house where the action happened. Empty if unavailable.
    </ResponseField>
    <ResponseField name="text" type="string">
      Description of the action, in English.
    </ResponseField>
    <ResponseField name="source_language_text" type="string">
      Description of the action in the legislature's own language. Empty if the original is in English.
    </ResponseField>
    <ResponseField name="action_type" type="string">
      Type of action, as given by the legislature. Empty if unavailable.
    </ResponseField>
    <ResponseField name="upstream_url" type="string">
      URL of the action on the legislature's website. Empty if unavailable.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Meaning |
|---|---|
| `403 Forbidden` | Your account doesn't have a valid subscription or hasn't accepted the Terms of Service. |
| `404 Not Found` | No bill has this `id`, or the bill belongs to a jurisdiction you can't access. |
