Returns the bills in the jurisdictions you can access, most recently updated first. Results use cursor pagination.

To poll for new bills and new activity on existing bills, use `updated_since`. See [Polling for changes](/api-reference/legislative/overview#polling-for-changes).

## Query parameters

<ParamField query="jurisdiction" type="string">
  Only return bills from these jurisdictions. Pass one or more comma-separated codes from [List jurisdictions](/api-reference/legislative/list-jurisdictions), such as `GB`.
</ParamField>

<ParamField query="updated_since" type="string">
  Only return bills that Parsagon updated at or after this time (ISO 8601). Filters on the bill's `last_seen`.
</ParamField>

<ParamField query="updated_before" type="string">
  Only return bills that Parsagon last updated before this time (ISO 8601). Filters on the bill's `last_seen`.
</ParamField>

<ParamField query="introduced_since" type="string">
  Only return bills introduced at or after this time (ISO 8601).
</ParamField>

<ParamField query="status_normalized" type="string">
  Only return bills with this status: `INTRODUCED`, `CONSIDERING`, `PASSED`, `FAILED`, `INACTIVE`, or `OTHER`.
</ParamField>

<ParamField query="session" type="string">
  Only return bills from this session. Use the legislature's session ID, as in the bill's `session` field.
</ParamField>

<ParamField query="bill_type" type="string">
  Only return bills of this type, such as `Government Bill`. Must match the bill's `bill_type` exactly.
</ParamField>

<ParamField query="is_act" type="boolean">
  Set to `true` to only return bills that have become acts, or `false` to exclude them.
</ParamField>

<ParamField query="external_id" type="string">
  Only return the bill with this ID in the legislature's own system.
</ParamField>

<ParamField query="search" type="string">
  Only return bills whose title, long title, or external ID contains this text. Case-insensitive.
</ParamField>

<ParamField query="page_size" type="number">
  The maximum number of bills to return. Defaults to `100`; maximum `500`.
</ParamField>

<ParamField query="cursor" type="string">
  Cursor token from the previous response's `next` or `previous` URL.
</ParamField>

## Response

<ResponseField name="next" type="string | null">
  URL for the next page of results, or `null` if this is the last page.
</ResponseField>

<ResponseField name="previous" type="string | null">
  URL for the previous page of results, or `null` if this is the first page.
</ResponseField>

<ResponseField name="results" type="array">
  Array of bills, most recently updated first.

## Errors

| Status | Meaning |
|---|---|
| `400 Bad Request` | A filter has an invalid value, such as a malformed date. |
| `403 Forbidden` | Your account doesn't have a valid subscription or hasn't accepted the Terms of Service. |
